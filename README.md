# rechnung-os-desktop
Rechnungen schreiben, E-Rechnungen lesen und die Buchhaltung dazu – auf deinem Mac oder Windows PC, ohne Konto, ohne Cloud und ohne Abo.  Seit dem 1. Januar 2025 muss jedes Unternehmen in Deutschland E-Rechnungen empfangen können – auch Kleinunternehmer, Freiberufler, Handwerker, Praxen und Vermieter.
